# Afya Pedagógico

Dashboard administrativo desenvolvido como projeto acadêmico para a disciplina de Ciência da Computação.

## 📌 Sobre o projeto

O Afya Pedagógico é um sistema de gerenciamento desenvolvido para facilitar o acompanhamento de alunos, projetos e indicadores pedagógicos.

O projeto possui uma interface administrativa responsiva, com tema claro e escuro, gráficos e páginas para cadastro e acompanhamento de informações.

## 🚀 Tecnologias utilizadas

- .NET 10
- Blazor WebAssembly
- MudBlazor
- C#
- HTML
- Git e GitHub

## 📂 Estrutura do projeto

- `Pages` — páginas do sistema
- `Components` — componentes reutilizáveis
- `Models` — modelos de dados
- `Services` — serviços utilizados pelo sistema
- `Layout` — estrutura de navegação e layout
- `Data` — dados utilizados no projeto

## 📊 Funcionalidades

- Dashboard administrativo
- Indicadores e cartões de resumo
- Gráfico de Receita x Meta
- Gráfico de clientes
- Cadastro de alunos
- Cadastro de projetos
- Edição e exclusão de projetos
- Relatórios
- Navegação entre páginas
- Tema claro e escuro
- Layout responsivo para dispositivos móveis

## 💡 O que aprendi

Durante o desenvolvimento do projeto, aprendi a:

1. Criar uma aplicação utilizando Blazor WebAssembly.
2. Trabalhar com componentes do MudBlazor.
3. Criar páginas e rotas dentro de uma aplicação Blazor.
4. Utilizar serviços para compartilhar dados entre páginas.
5. Criar formulários com validação.
6. Trabalhar com tabelas, gráficos e indicadores.
7. Utilizar Git e GitHub para versionar o projeto.
8. Desenvolver uma interface responsiva para diferentes tamanhos de tela.
